What to look at

Active holds Seats reserved during checkout, counting down to expiry. An expired hold stops counting the instant it lapses — the sweep job only tidies the row afterwards.
Audit trail Append-only history of every booking state change, written in the same transaction as the change itself. UPDATE and DELETE are revoked from the application role, so this is immutable at the database level rather than by convention.
Security feed Failed logins, refresh-token replay, authorization denials, rate limits and card-testing detections — each carrying the rule hits that explain why it fired. Run make demo-carding and watch it populate.
